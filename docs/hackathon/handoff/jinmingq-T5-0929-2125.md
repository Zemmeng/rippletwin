# T5 Execution pack and equipment hire cost (proposal #48 step ⑧ and the hire cost in step ④, backend only) — handoff

*Archived from the hackathon (29 Sep – 1 Oct 2026). Translated from the original Chinese; superseded details are kept as they were.*

## 1. Facts
- What was done: `apps/api/public/js/pack.js` (pure functions that run in the browser, not a new endpoint); the web page is unchanged
  - `quote()`: on-site equipment → RPM inventory item (`equipment.json` from `apps/roads`) × count × days = hire cost; items over the stock level or not matching the inventory (e.g. ROAD CLOSED) are flagged, and unmatched items are not priced
  - `stockCheck()`: several worksites on the same days share one inventory; reports which equipment runs short on which day
  - `buildPack()` / `packText()`: the execution pack (location, time, decision, quote, every VMS frame, signs, configuration check, who to notify) and its Chinese and English text versions
  - Equipment in the register can carry an optional `item` and `qty` (`worksites.js`)
- Where it stopped (09-29 21:25): code and tests done and committed on the branch, not pushed yet
- Branch / PR: `jinmingq/api/T5-pack`, stacked on `jinmingq/api/T5-explain` (#54), which is stacked on #53
- Verification: `bash apps/api/test.sh` all passing (summary line in the commit body); `pack.test.mjs` checks the Lonsdale quote item by item against the real inventory + real link lengths, and the checks and notifications for the full Little Bourke closure; removing the "assumed value" notice or switching off the bus notification turns the tests red (tried, then reverted)
- Not yet verified: page integration; print layout
- Cost this session: 0
