# T5 AI explanation (proposal #48 step ⑥, backend only) — handoff

*Archived from the hackathon (29 Sep – 1 Oct 2026). Translated from the original Chinese; superseded details are kept as they were.*

## 1. Facts
- What was done: added `POST /api/explain` and the browser-side `public/js/explain.js` to `apps/api`; the web page is unchanged
  - Input: the engine numbers for 1–5 plans (network-wide delay, queue, extra wait per vehicle, detour share, trams and buses, pedestrians, hire cost, duration, extra minutes per person for each persona); output: for each plan a summary / pros / cons / who is hit hardest / risks, one lean (which plan and why), and the fixed "the person in charge decides"
  - For now there is only a rules version (`src: "rule"`, deterministic, free); the lean = the plan with the smallest straight sum of vehicle-minutes + rider-minutes + pedestrian-minutes; `why` states that this is not weighted by occupancy, and notes when the hire cost is not the lowest and when there are risks
  - Number guard: every number in an explanation must trace back to a number in the request or to a plan total (`allowedNumbers()`), and sentences that cannot be traced are dropped; future LLM answers also go through `sanitizeExplain()`, which means they cannot remove the rules version's risks, and extra fields (e.g. `final`) are dropped
  - `optionFromRun(id, name, result of be.run(), { hire_aud, days })`: the page does not have to assemble the request itself
- Where it stopped (09-29 21:05): code and tests done and committed on the branch, not pushed yet
- Branch / PR: `jinmingq/api/T5-explain`, stacked on `jinmingq/api/T5-worksites` (#53); once #53 is merged, this branch contains only the explanation changes
- Verification: `bash apps/api/test.sh` all passing (summary line in the commit body); the real-engine section of `explain.test.mjs`: Lonsdale with only ROADWORK AHEAD (network-wide delay 10,527 vehicle-minutes, queue 921 m) vs with an extra frame USE RUSSELL ST (5,727, 546 m) → leans towards adding the frame; with the number guard switched off, 3 negative assertions turn red (tried, then reverted)
- Not yet verified: the LLM version (not built); page integration; production deployment
- Cost this session: 0
