# handoff/done/: processed handoff notes

*Archived from the hackathon (29 Sep – 1 Oct 2026). Translated from the original Chinese; superseded details are kept as they were.*

Read-only. Once the lead had processed a handoff note (the shared-file changes in section 2 made, the decisions asked for in section 3 recorded in [`docs/decisions.md`](../../../decisions.md)), the note was moved here with `git mv` and **never deleted**.
To see who stopped where, and when, on a given task: `ls docs/hackathon/handoff/done/*T3*`.

The convention and an index of every note are in the [parent README](../README.md).
