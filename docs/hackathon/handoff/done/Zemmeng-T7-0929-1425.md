## 1. Facts
- What was done: following `docs/hackathon/specs/ai-flow.md`, built the middle part of the pipeline as a runnable skeleton; all MOCK, no money spent
  - `apps/engine` (T4's territory, held by the lead for now): ① find the affected vehicles and detour routes → ② scenario cards → ④ two-point calibration → ⑤ diversion, BPR + deterministic queueing for delay → ⑥ clash cost D(A+B) − D(A) − D(B) → ⑦ re-run each of the advisor's suggested changes. When a queue grows, ask one more round with "how long the queue ahead is" and average the two rounds (MSA, to stop it oscillating). Until the real network arrives, uses a small 5 × 9 Hoddle Grid (real street names, assumed traffic)
  - `apps/api` (T5's territory, held by the lead for now): a Cloudflare Worker (`/api/health`, `/api/persona`, `/api/advisor`, `/api/worksites`) + browser-side `askPersonas` / `askAdvisor` (fallback chain: answers file → Worker → keyword rules) + validation of on-sign text + cache keys + a spending fuse; prompts live only in `apps/api/prompts.md`
  - `docs/reference/interfaces.md` (the contract) upgraded to v2: works plan, scenario cards and answers, engine results, planning advisor, HTTP API
  - Registered in: `apps/README.md`, `.github/CODEOWNERS`, `.claude/launch.json` (new `api`, port 8788), the module table in `docs/hackathon/plan.md`, `docs/hackathon/task-board.md` (T7; T4 / T5 note what to do next)
