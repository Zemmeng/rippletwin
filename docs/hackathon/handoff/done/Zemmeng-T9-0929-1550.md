  - Accepts T12 #31's `route_familiarity` (= `familiar`). Tested with #31's params.json: mix, anchors and familiarity for all 4 types are used, errors is empty

  - Task T13 for @unicornnnnnny, `docs/hackathon/specs/T13-web-wiring-PRD.md`: the page connects only to `backend.js`, and the PRD maps each preset number to the summary field that replaces it
  - In `apps/engine/test.sh`, every `$var` immediately followed by a full-width character changed to `${var}` (the new check from #30)
