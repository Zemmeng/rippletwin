# Editable RippleTwin workflow

*Archived from the hackathon (29 Sep – 1 Oct 2026). Written in English at the time (PR #52, @jinmingq) and kept as it was; the status labels it describes are a 29 Sep snapshot.*

Open `rippletwin-business-workflow.svg` in a vector editor or give the file directly to Claude for further edits. The 1920 × 1080 SVG contains editable text and vector shapes, not an embedded bitmap. Fonts use Georgia and Arial with standard fallbacks; another editor may substitute fonts.

This is a presentation redraw of the user-approved v3 concept. It separates VMS wording from works configuration and returns revised plans to both interpretation and simulation. The advisor never computes delay. Baseline and proposed scenarios use the same engine.

Status labels deliberately preserve the supplied 29 Sep 2026 pre-screen snapshot. They are not a current implementation audit: repository activity after that snapshot includes tram and pedestrian integration. The pitch owner should update status labels against the actual demo before presenting. Keep LLM reading and deterministic route choice distinct.

Validation: rendered at 1920 × 1080 in Chromium and visually reviewed; 58 editable SVG text elements; no embedded raster image or external resources. No application code changed.
