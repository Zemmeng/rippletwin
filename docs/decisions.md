# Decision log

The decisions that shaped RippleTwin, recorded by Team Uncapped before and during the FEIT Hackathon Festival 2026 (29 Sep – 1 Oct 2026). Each row says what was decided, why, which alternatives were rejected, and who made the call. Code comments that cite an ID such as `D-0929-1435` point to this file.

- **Append-only.** Rows are never edited or deleted. A decision is changed by appending a new row that names the one it changes ("Overrides D-…", "Amends D-…"). `scripts/check.sh` check [3] rejects deleted lines on module branches, and `.gitattributes` sets `merge=union` so that concurrent appends keep both sides. The **Superseded by D-…** and **Amended by D-…** markers on earlier rows were added when the log was translated; nothing else about those rows changed.
- **Settled means settled.** A proposal that conflicts with a row must name it ("this conflicts with D-0929-1435") and go to the team; nobody, human or AI, quietly reopens a decision.
- **IDs.** `D-01` to `D-11` are the process defaults set before the event (26 Sep). Decisions made during the event use `D-MMDD-HHMM`: the month, day, hour and minute in Melbourne time (AEST, UTC+10) when the row was written, so that people appending at the same time don't collide. Rows are in the order they were appended, so the IDs are not strictly sorted.
- **References.** `T<n>` is a task on the event task board ([docs/hackathon/task-board.md](hackathon/task-board.md)); `#<n>` is a pull request or issue in this repository. "The lead" is @Zemmeng. Translated from the original Chinese: chat quotes are paraphrased, and paths are updated where a file has since moved.
